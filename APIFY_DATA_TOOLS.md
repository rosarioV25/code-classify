# Apify Data & Automation Tools

A collection of production-oriented Apify Actors maintained by the same developer. These tools expose structured outputs through Apify datasets and APIs, support scheduling and automation, and use pay-per-event pricing with Apify platform usage billed separately by the platform.

## Document, OCR and AI data pipelines

- [Image & PDF OCR Extractor API](https://apify.com/zenomastro/image-ocr-text-extractor) — OCR for images and scanned PDFs, 100+ languages, confidence scores, bounding boxes and Markdown output.
- [PDF to JSON/CSV/Markdown API](https://apify.com/zenomastro/pdf-to-structured-data) — extract page text, metadata, tables and Markdown from PDFs.
- [Text Splitter & RAG Chunker API](https://apify.com/zenomastro/text-splitter-for-llm) — recursive overlap-aware chunking for embeddings, vector databases and LLM/RAG pipelines.
- [Data Cleaner & Normalizer API](https://apify.com/zenomastro/data-cleaner-normalizer) — normalize JSON/CSV records, emails, phones and dates, remove empty values and deduplicate data.

## Search, SEO and website intelligence

- [Google Autocomplete Scraper API](https://apify.com/zenomastro/google-autocomplete-keywords) — recursive long-tail keyword discovery and change monitoring.
- [Broken Link Checker API](https://apify.com/zenomastro/broken-link-checker-pro) — crawl links, assets and redirects with persistent change monitoring.
- [Schema Markup Extractor API](https://apify.com/zenomastro/schema-markup-extractor-pro) — JSON-LD, Microdata, RDFa and technical SEO audit with JavaScript rendering.
- [Sitemap URL Extractor API](https://apify.com/zenomastro/sitemap-url-extractor-pro) — sitemap extraction, indexability checks and snapshot comparison.
- [Website Screenshot API](https://apify.com/zenomastro/website-screenshot-pro) — PNG/JPEG/WebP/PDF capture, device presets and visual change detection.

## Reviews, reputation and market research

- [Apple App Store Reviews Scraper API](https://apify.com/zenomastro/apple-app-store-reviews-pro) — iOS reviews across storefronts for ASO and product research.
- [Google Play Reviews Scraper Pro API](https://apify.com/zenomastro/google-play-reviews-pro) — Android reviews, ratings, app versions and developer replies.
- [Google Play Reviews Scraper API](https://apify.com/zenomastro/google-play-reviews-reliable) — filtered review collection with version/month/topic insights.
- [Booking.com Reviews Scraper API](https://apify.com/zenomastro/booking-reviews-reliable) — hotel reviews, guest/stay metadata and monitoring.
- [TripAdvisor Reviews Scraper API](https://apify.com/zenomastro/tripadvisor-reviews-reliable) — hotels, restaurants, attractions and travel feedback.
- [Trustpilot Reviews Scraper API](https://apify.com/zenomastro/trustpilot-reviews-reliable) — reputation research, deep-history mode, replies, filters and incremental monitoring.
- [Google Ads Transparency Scraper API](https://apify.com/zenomastro/google-ads-transparency-pro) — public ad creatives, advertisers, formats and competitor research.
- [Google Trends Scraper API](https://apify.com/zenomastro/google-trends-reliable) — keyword interest, regions, related queries and daily trends.

## YouTube data

- [YouTube Comments Scraper API](https://apify.com/zenomastro/youtube-comments-reliable) — video, Shorts, channel, playlist and search comment/reply extraction.
- [YouTube Transcript Scraper API](https://apify.com/zenomastro/youtube-transcript-reliable) — bulk transcripts, subtitles, SRT/VTT and RAG chunks.

## Usage

Each Actor has a ready-to-run input form, API endpoints, downloadable datasets, scheduling support and public starter/use-case tasks on Apify. Open the Actor page to inspect the input schema, pricing and current capabilities before running it.
